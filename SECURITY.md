# Безопасность и ответственное использование

## Допустимое использование

Dragon Forge X предназначен только для авторизованного тестирования: собственных систем, лабораторий, CTF и целей с явным письменным разрешением владельца.

Запрещено использовать проект для:

- несанкционированного сканирования;
- обхода контроля доступа;
- кражи данных или учётных записей;
- нарушения доступности сервисов;
- сокрытия вредоносной активности.

## Сообщение об уязвимости проекта

Не публикуйте чувствительные сведения в открытом issue. Для приватного сообщения используйте GitHub Security Advisories или контакт, указанный владельцем репозитория.

В сообщении укажите версию, воспроизводимые шаги, влияние и безопасное доказательство концепции. Не прикладывайте реальные секреты, персональные данные или данные чужих систем.

## Обращение с результатами

Скан-отчёты и PoC могут содержать секреты и персональные данные. Храните их локально или в закрытом хранилище, удаляйте перед публикацией и проводите проверку истории Git.
